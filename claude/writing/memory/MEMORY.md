# Writing memory

One file per memory, beside this index. Read a memory before writing the kind of text it covers. Each correction adds one file here and one line below.

- [Consider the audience](feedback_consider_the_audience.md) - who reads it decides register and detail; strip internal detail going outward
- [Lead with the answer](feedback_lead_with_the_answer.md) - one question, one sentence, carrying the keyword
- [Plain language](feedback_plain_language.md) - literal, common words; no idiom, jargon or drama
- [AI tells](feedback_ai_tells.md) - the markers, and the nine-question test every sentence passes
- [Agree plainly](feedback_agree_plainly.md) - "Agreed", "ack", "I stand corrected"; never legalese or a narrated retraction
- [No em-dash, ASCII only](feedback_no_em_dash_ascii_only.md) - hyphen, straight quotes, "..."; sweep before done
- [Timeless prose](feedback_timeless_prose.md) - current state only; no history, markers or line numbers
- [Brevity in bug reports](feedback_brevity_in_bug_reports.md) - the testcase and the raw output are the report; no teaching
- [Write to the reader](feedback_write_to_the_reader.md) - claim, mechanism, number; three to five lines; warm, never clipped
- [Report, don't direct](feedback_report_dont_direct.md) - observation plus a soft suggestion; the owner decides
- [Claims match evidence](feedback_claims_match_evidence.md) - "completed" and "tests pass" mean nothing skipped; no "measured", no "honest"
- [Show the deliverable](feedback_show_the_deliverable.md) - print the artifact, never a changelog
- [Paste-ready text](feedback_paste_ready_text_clean.md) - over one to three paragraphs goes in a file; no prefix, no indent
- [Jira markup habits](feedback_jira_markup_habits.md) - {{..}}, {code:lang}, no bold or headers, the hyphen escape only in {{..}}
- [Jira markup reference](reference_jira_markup.md) - the wiki syntax
- [Bug report wording](feedback_bug_report_wording.md) - "the proposed fix"; full versions; titled output blocks; one bug per report
- [No boasting, no false warnings](feedback_no_boasting_no_false_warnings.md) - never report compliance; warn only on a real gap
- [Self-contained posts](feedback_self_contained_posts.md) - re-state the whole finding after a background job
- [Closing question](feedback_closing_question_simple.md) - one line, "a or b?"
- [Summary format](feedback_summaries_tickbox_format.md) - a status column in chat only; 10 words per line
